# Bearing RUL Prediction

## Project Overview
This project focuses on Remaining Useful Life (RUL) prediction for bearings using deep learning approaches.

## Directory Structure
- `data/`: Contains raw, processed, and external datasets
- `src/`: Source code organized by modules
- `notebooks/`: Jupyter notebooks for exploration and analysis
- `checkpoints/`: Saved model weights
- `results/`: Output figures, tables, and logs
- `paper/`: Documentation for academic paper
- `docs/`: Technical documentation
- `tests/`: Unit tests

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Download data using `src/data/download.py`
3. Preprocess data using `src/data/preprocessing.py`
4. Train models using `src/training/train.py`
